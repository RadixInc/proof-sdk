# Architecture decision records

One file per decision. A new record is `docs/adr/YYYYMMDD-slug.md`:

- `YYYYMMDD` is the day you write the record.
- The slug is lower-case words joined by hyphens, for example `20261002-market-rollup-reads-parquet`.
- Cite a record by its filename without `.md`: `ADR-20261002-market-rollup-reads-parquet`.

Records written before 2026-10-02 keep their `YYYY-MM-slug.md` names and their old citations.
This is the organization rule from kit 4.0.0 ([RadixInc/agentic-standards-kit](https://github.com/RadixInc/agentic-standards-kit/blob/main/docs/adr/kit/20261002-adr-filenames-are-dated.md)).
